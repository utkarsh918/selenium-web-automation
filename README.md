# Selenium Web Automation Testing

## Overview
Web automation testing project developed using Java,
Selenium WebDriver and Maven.

## Tech Stack
- Java
- Selenium WebDriver
- Maven
- ChromeDriver

## Test Coverage
- Browser automation
- Web element interaction
- Alerts handling
- Keyboard interactions
- Exception handling

## Project Structure
src/
├── main/
└── test/

## How to Run
1. Clone the repository
2. Import as a Maven project
3. Install required dependencies
4. Run the test classes
